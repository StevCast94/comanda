## 2. LO QUE HAY QUE CONSTRUIR

### A. Login Unificado (email O username)
**Archivo:** `backend/src/routes/auth.ts`
```
POST /api/auth/login  { email?: string, username?: string, password: string }
→ Buscar por email o username → bcrypt verify → JWT con { userId, restaurantId, role }
→ Si user.active === false → 403
→ Actualizar lastLogin
```

### B. Panel SUPERADMIN
**Ruta:** `/superadmin`
**5 secciones:**
- **B1. Restaurantes** — CRUD completo (crear = auto-crea Restaurant + User ADMIN)
- **B2. Suscripciones** — ver/cambiar plan (TRIAL ↔ ACTIVE ↔ CANCELLED)
- **B3. Tickets soporte** — modelo `SupportTicket`, ADMIN crea → SUPERADMIN responde
- **B4. Métricas globales** — restaurantes activos, revenue total, pedidos hoy
- **B5. Auditoría** — log de acciones críticas

### C. Panel ADMIN de Restaurante
**Ruta:** `/admin`
- **C1. Usuarios operativos** — crear con username+password+role (sin email)
- **C2. Tickets soporte** — crear/ver historial
- **C3. Métricas** — pedidos, revenue, usuarios activos

### D. Endpoint /api/metrics (para Matrix)
**Ruta:** `GET /api/metrics` (público)
```json
{ "restaurants_total": N, "restaurants_active": N, "users_total": N, "orders_today": N, "revenue_today": "$N.NN", "revenue_month": "$N.NN", "subscriptions_trial": N, "subscriptions_active": N, "support_tickets_open": N, "updated_at": "ISO" }
```
